# claude

Personal Claude Code project. Skills installed under `.claude/skills/` are loaded automatically in any Claude Code session run against this repo.

## Installed: taste-skill

Source: https://github.com/Leonxlnx/taste-skill (MIT license, see `TASTE-SKILL-LICENSE`)

Frontend design skills for building non-generic, premium-looking websites and apps:

| Skill | Purpose |
|---|---|
| `taste-skill` | Default anti-slop frontend skill (landing pages, portfolios, redesigns) |
| `taste-skill-v1` | Previous version, kept for backward compatibility |
| `gpt-tasteskill` | GSAP-heavy motion/UX variant |
| `soft-skill` | High-end agency visual design (fonts, spacing, shadows) |
| `minimalist-skill` | Editorial minimalist UI |
| `brutalist-skill` | Industrial/brutalist UI |
| `redesign-skill` | Audits and upgrades existing sites |
| `brandkit` | Brand-kit / identity board image generation |
| `image-to-code-skill` | Image-first design-to-code workflow |
| `imagegen-frontend-web` | Website design reference image generation |
| `imagegen-frontend-mobile` | Mobile app screen concept generation |
| `stitch-skill` | Generates `DESIGN.md` for Google Stitch |
| `output-skill` | Enforces complete, unabridged code output |

See `TASTE-SKILL-README.md` and `TASTE-SKILL-CHANGELOG.md` for upstream documentation.
